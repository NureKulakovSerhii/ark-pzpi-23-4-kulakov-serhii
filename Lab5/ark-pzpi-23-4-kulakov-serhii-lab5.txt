　　　　3 ОПИС ВИКОНАННОЇ РОБОТИ
　　　　У ході роботи було успішно реалізовано комплексне розгортання веб-застосунку для оренди малих складських приміщень. Було здійснено публікацію Web-API на спеціалізованій платформі для .NET-додатків, що забезпечило готове до роботи середовище з оптимально налаштованими серверами та вбудованою базою даних. Ключовим моментом стало розв’язання критичної проблеми синхронізації схеми бази даних із програмним кодом. Після першого запуску виникла необхідність у автоматизації міграцій. Цей механізм було реалізовано таким чином, що додаток при старті самостійно аналізує структуру бази даних та застососвує всі необхідіні оновлення, гарантуючи цілісність даних та актуальність схем (Код розв’язання проблеми наведено в Додатку А.1).
　　　　Для забезпечення безпеки конфігурація була чітко розділена між файліми для локальної розробки та файлами для продакшен-середовища, що запобігло використанню тестових ключів та рядків підключення у фінальному середовищі. Паралельно було підготовлено повноцінну інфраструктуру контейнеризації, що включає оптимізований Dockerfile (Код Dockerfile наведено у Додатку А.2) та docker-compose.yml (Код docker-compose.yml наведено у Додатку А.3) файл для запуску та координування всіх компонентів системи - від веб-сервісу до сервера баз даних.
　　　　Як результат, система стала повністю доступною через інтерфейс Swagger за публічною адресою, демонструючи стабільну роботу всіх RESTful ендпоїнтів. Розгорнута архітектура забезпечує масштабованність та відмовостійкість, а підготовлені конфігурації Docker дозволяють швидко розгортати ідентичні середовища на будь-якій платформі з підтримкою контейнеризації, що відповідає сучисним стандартам DevOps та CI/CD практикам.

А.1 Програмний код вирішення проблеми з автоматичними міграціями:
using (var scope = app.Services.CreateScope())
{
    var dbContext = scope.ServiceProvider.GetRequiredService<AppDbContext>();
    try
    {
        await dbContext.Database.MigrateAsync();
        Console.WriteLine("Migrations applied successfully");
    }
    catch (Exception ex)
    {
        Console.WriteLine($"Error applying migrations: {ex.Message}");
    }
}
А.2 Код файлу Dockerfile:
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY API/API.csproj API/
WORKDIR /src/API
RUN dotnet restore API.csproj

RUN dotnet publish "API/API.csproj" -c Release -o /app/publish
FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS runtime
WORKDIR /app
COPY --from=build /app/publish .

EXPOSE 80
ENTRYPOINT ["dotnet", "API.dll"]
